# JavaScript Learning & Revision Journey


This repository was created as part of my journey to learn JavaScript for Test Automation, with a focus on supporting automation using Cypress.

* I am a Manual QA Engineer, and this repo helps me:
   - Build a strong foundation in JavaScript
   - Revise core JavaScript concepts regularly
   - Practice JavaScript from a tester’s point of view
   - Prepare myself for automation testing with Cypress
 
# Goals of This Repository

   - Understand JavaScript basics step by step
   - Learn only tester-relevant JavaScript concepts
   - Practice with simple and real-time examples
   - Use this repo as a revision reference in the future
   - Gain confidence in writing automation scripts

# Topics Covered (Beginner Friendly)

   - Variables (var, let, const)
   - Data Types (String, Number, Boolean, Array, Object)
   - Operators & Conditions
   - Loops (for, while)
   - Functions
   - Arrow Functions
   - JavaScript Arrays & Objects (important for Cypress)
   - Basic DOM concepts
   - JavaScript concepts commonly used in Cypress automation

# Learning Approach

   - Daily practice for 1 hour
   - Simple explanations with examples
   - Focus on clarity over complexity
   - Hands-on coding instead of theory only
   - Gradual transition from JavaScript → Cypress

# Future Plan

   - Add Cypress examples using JavaScript
   - Write automation test scripts
   - Improve JavaScript logic and confidence
   - Convert manual test scenarios into automation scripts
